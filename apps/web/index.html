PANDUAN STAF

SOP saat terjadi gangguan

Ikuti urutan ini agar transaksi dan stok tidak digandakan.

1

Internet putus

  1. Jangan logout atau hapus data aplikasi.
  2. Lanjutkan transaksi offline setelah katalog pernah termuat.
  3. Catat nomor transaksi dan jangan input ulang di perangkat lain.
  4. Saat online, buka Sinkronisasi dan tunggu sampai antrean selesai.
2

Printer gagal

  1. Transaksi tetap sah bila pembayaran sudah berhasil.
  2. Periksa printer menyala dan sudah dipasangkan.
  3. Gunakan Riwayat Struk untuk cetak ulang.
  4. Jangan membuat transaksi kedua hanya untuk mencetak.
3

Scanner tidak membaca

  1. Pastikan mode scanner HID dan mengirim Enter.
  2. Fokuskan kursor ke pencarian barcode.
  3. Gunakan kamera atau cari nama produk sebagai cadangan.
  4. Laporkan barcode salah melalui Insiden Produksi.
4

Data atau total meragukan

  1. Hentikan transaksi berikutnya pada perangkat tersebut.
  2. Jangan mengedit database atau menghapus aplikasi.
  3. Catat layar, waktu, kasir, dan langkah kejadian.
  4. Owner periksa Kesehatan Sistem dan buat insiden.
